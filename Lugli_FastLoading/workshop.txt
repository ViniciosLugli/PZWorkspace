description=[h1]What it does[/h1]
description=[list]
description=[*]Skips the intro logos, which play [i]after[/i] loading has already finished
description=[*]Shows a real loading screen instead of a frozen window: progress bar, phase and elapsed time
description=[*]Scans your mod folders on several threads, with the same override order
description=[*]Decodes textures and tilesets in parallel, and caches compiled shaders
description=[*]Parses tile geometry in the background
description=[*]Loads vehicle textures while you sit at the menu, not while you wait to spawn
description=[*]Builds the loot table once, after every mod has added to it, not once per mod
description=[*]Speeds up Gunworks loot, if you run that mod
description=[*]Opens the options screen without the long pause
description=[*]Sizes itself to your CPU and to the memory the game is given
description=[/list]
description=Every part can be switched off on its own, and a part that fails its self-check turns itself off.
description=
description=[h1]FAQ[/h1]
description=[list]
description=[*][b]ZombieBuddy asks me to approve a Java mod.[/b] Expected. Approve it once and enable the mod.
description=[*][b]Is it signed?[/b] Yes, and ZombieBuddy's author list names me. A signature proves who built it, not what it does, so the full source is on GitHub.
description=[*][b]Where do the switches below go?[/b] In the [b]vmArgs[/b] list of ProjectZomboid64.json in the game folder, not in Steam launch options. A game update resets that file, so add them again after one.
description=[*][b]The loading screen looks different.[/b] That is this mod. Add [i]-Dfastloading.progress=off[/i] for the vanilla screen, or [i]-Dfastloading.warningms=-1[/i] to bring back the photosensitivity notice.
description=[*][b]I play from a hard disk.[/b] Add [i]-Dfastloading.iothreads=2[/i] so the folder scan seeks less.
description=[*][b]Dedicated server?[/b] Only the loot fixes run there. The rest is client side.
description=[*][b]Add or remove it mid-save?[/b] Yes. It writes nothing to your save or your game folder.
description=[*][b]Something looks wrong.[/b] Add [i]-Dfastloading.logo=keep -Dfastloading.assets=off[/i] to turn off the parts most likely to cause it. If that fixes it, open an issue on GitHub.
description=[/list]
