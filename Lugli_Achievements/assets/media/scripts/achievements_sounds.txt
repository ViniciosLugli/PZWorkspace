/* The unlock stings. One block per clip; the player picks between them in the achievements
 * window, where the dropdown plays what it selects.
 *
 * A MOD CANNOT SHIP AN FMOD BANK, so these are loose OGGs resolved through
 * ZomboidFileSystem by FMODManager.loadSound. `event =` could only name an event
 * that already exists in a vanilla bank, which ours do not.
 *
 * EVERY VALUE CARRIES A TRAILING COMMA, INCLUDING THE LAST. ScriptParser.readBlock
 * emits a value only when it reaches a ',' and returns immediately on '}', so a
 * final key without one is silently dropped.
 *
 * The names are prefixed because GameSounds keys ONE flat map on the bare name and
 * ignores the module, so a later-loading mod calling something "Soft" would replace ours.
 *
 * is3D = false and no distanceMin/distanceMax: this is interface feedback for the
 * player who earned it, not a thing happening at a place in the world. category = UI
 * puts it under the player's own UI volume slider rather than under Ambient, which
 * is where vanilla files every sound the interface makes.
 *
 * One volume for all seven, because tools/achievements-audio.sh peak normalises every clip to
 * -1 dBFS on encode and Sound.lua applies the player's own gain per play on top. A per-clip trim
 * here would be correcting the same thing a third time, in a file nothing verifies.
 */
