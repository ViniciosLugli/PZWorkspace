/* The sounds Lugli - Dead Man's Stash ships. Every clip is a loose OGG under media/sound, cut and
 * encoded by tools/dms-audio.sh from the CC0 recordings in art/dms-audio/ (SOURCES.md there); a
 * mod cannot ship an FMOD bank, so `event =` is never an option here.
 *
 * EVERY VALUE CARRIES A TRAILING COMMA, INCLUDING THE LAST. ScriptParser.readBlock emits a
 * value only when it reaches a ',' and returns immediately on '}', so a final key without one
 * is silently dropped. distanceMin and distanceMax go through Integer.parseInt.
 *
 * Names are prefixed because GameSounds keys one flat map on the bare name and ignores the
 * module, so a later-loading mod with the same name would replace ours. Several clip blocks are
 * variants of one sound: the engine picks one per play.
 *
 * LOUDNESS LIVES IN THE FILES, NOT HERE. The encoder normalises each clip against vanilla clips
 * decoded from the FMOD banks (dial tick -38 LUFS, pick pin -36, dial contact and keypad key -32,
 * drill loop -33, keypad accept -28, bolt cut -27, keypad deny -26), so `volume` stays at its
 * default 1.0 as it does in every vanilla script.
 *
 * DISTANCES follow powergrid_sounds.txt: full level inside distanceMin, -6 dB per doubling out to
 * distanceMax, where FMOD holds the level, so every pair keeps max at ten times min (-20 dB). A
 * pin or a dial tick is for the survivor at the lock; the drill carries across a building.
 *
 * CATEGORY is Object, as vanilla's lock, door and barricade sounds are: every one of these
 * happens at a lock or a safe.
 */
