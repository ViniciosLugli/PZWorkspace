description=[b]No dependencies.[/b] Each fix turns on only when the mods it fixes are active. It first checks that their code is still the version it was written for, and after an update it stands down instead of guessing. Every fix has its own switch in the sandbox options.

description=[h1]Questions[/h1]
description=[list]
description=[*][b]Load order?[/b] Anywhere after the mods it fixes. The end of the list is simplest.
description=[*][b]Can I add it to a running save?[/b] Yes.
description=[*][b]Is it safe to remove?[/b] Yes. It adds no items or objects, so nothing breaks when it is gone.
description=[*][b]Multiplayer?[/b] Install it on the server and on every client, as with any mod. Tested in single player so far.
description=[*][b]Did it load?[/b] Your console.txt has a line starting with [i][Lugli/ModpackFixes][/i] that lists every fix and whether it installed, or why it was skipped.
description=[/list]
